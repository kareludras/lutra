Setup

  1. Download the binary

    Pick the file for your system above.

  2. Allow it to run

    Windows: if SmartScreen warns, choose More info, then Run anyway.

    Linux: chmod +x lutra-linux-x86_64

    macOS: chmod +x lutra-macos-arm64 && xattr -d com.apple.quarantine lutra-macos-arm64

  3. Add it to a chess GUI

    Lutra has no board of its own. Add it as a UCI engine in Cute Chess, Arena, BanksiaGUI or En Croissant.

Option: Hash in MB, default 16. Run lutra bench in a terminal for a quick self-test.

Inside

  • Move generation

    Bitboards, legal moves, perft-validated against standard positions.

  • Search

    Iterative deepening, PVS, transposition table, null move pruning, late move reductions, quiescence.

  • Evaluation

    Tapered PeSTO tables, pawn structure, bishop pair, rook files, mobility.

  • Testing

    SPRT harness on fastchess and an Elo check on every pull request.
